# 🚀 Portfólio — Ailton Rodrigo

Meu portfólio pessoal com design dark e profissional. Apresenta minha trajetória, habilidades e projetos para clientes e recrutadores.

## 🔗 Demo

[Acesse o portfólio](https://ailtinho-filho.github.io/portfolio)

## 📋 Sobre

Site pessoal construído do zero com HTML, CSS e JavaScript puro — sem frameworks. Design dark com tipografia moderna (Syne + Space Mono), animações suaves e layout responsivo.

---

## ✨ Seções

- **Hero** — apresentação com nome em destaque e chamada para ação
- **Sobre** — resumo pessoal, formação e informações rápidas
- **Skills** — habilidades em Front-end, Back-end e IA como ferramenta
- **Projetos** — trabalhos desenvolvidos com links para o GitHub
- **Voluntariado** — LEO Clube Bauru Norte (Presidente 2024/2025)
- **Contato** — formulário + links LinkedIn e GitHub

## 🛠️ Tecnologias

| Tecnologia | Uso |
|---|---|
| HTML5 | Estrutura da página |
| CSS3 | Estilização, animações e responsividade |
| JavaScript | Interações e manipulação do DOM |
| Google Fonts | Tipografia (Syne + Space Mono) |

---

## 💡 Diferenciais

- Design 100% autoral — sem Bootstrap ou frameworks CSS
- Uso de variáveis CSS para tema consistente
- Animações de entrada com `@keyframes`
- Layout responsivo com CSS Grid e Flexbox
- Seção dedicada ao uso de **IA como ferramenta** de desenvolvimento
